# SVM
Практическая работа 3, вариант 29 ИКБО-23-25
## Синтаксис языка ассемблера
Язык спроектирован в духе языков высокого уровня, используя "алгебраический" синтаксис:

* Каждую команду нужно описывать с новой строки в формате "результат = операнд(ы)"
* "*" - обозначение адреса в памяти
* Числа без префикса считаются константами или смещением (в зависимости от команды)

## Поддерживаемые команды

* Загрузка константы. Записывает число C в ячейку памяти по адресу B.

Формат записи: 
```text
*B = C
```
* Чтение значения из памяти. Записывает в ячейку памяти по адресу B результат смещения значения в ячейке памяти по адресу D на C.

Формат записи:
```text
*B = *(*D + C)
```
* Запись значения в память. Записывает в ячейку памяти по адресу C значение в ячейке памяти по адресу B.

Формат записи:
```text
*C = *B
```
* Бинарная операция: вычитание. Записывает в ячейку памяти по адресу D результат вычитания значения из ячейки памяти по адресу B из значения из ячейки памяти по адресу C.

Формат записи: 
```text
*D = *C - *B
```
## Запуск программы

```bash
python src/main.py <путь к исходному файлу с текстом программы> <путь к двоичному файлу результату> --test(опционально)
```
* `--test` используется для запуска в тестовом режиме для показа внутреннего представления ассемблированной программы
